# Security tools to install on a new system

Tools I want to install whenever I set up a new machine.

- [nono](https://github.com/always-further/nono) — Sandbox any AI agent in seconds; zero setup, zero latency.
- [safe-chain](https://github.com/AikidoSec/safe-chain) — Blocks malicious packages installed via npm, yarn, pnpm, npx, pnpx, pip, uv, and poetry. Free, no tokens required.
