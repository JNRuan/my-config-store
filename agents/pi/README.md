# Pi Extensions

## pi-guardrails

[pi-guardrails](https://github.com/aliou/pi-guardrails) — Security hooks for Pi: prevents dangerous operations, protects env files, and gates destructive commands.

### Setup

`guardrails.json` in this folder is the configuration for the extension. Copy it to `~/.pi/agent/extensions/`:

```sh
cp guardrails.json ~/.pi/agent/extensions/
```
